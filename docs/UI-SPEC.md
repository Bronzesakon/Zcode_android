# UI-SPEC —— 原生安卓界面施工规格（2026-10-17 定稿）

> 本文件是界面层的**唯一口径**。所有页面、控件、布局、交互都以这里为准；
> 与代码不一致时，先改这里再改代码。设计令牌来自 `design/tokens/`，
> 协议字段来自 `docs/remote-v4/` 与 `docs/desktop/`。

## 0. 全局

| 项 | 决定 |
|---|---|
| 导航 | 底部双 Tab：**对话** / **设置**。无设备切换器，只配对一台电脑。 |
| 配对对象称谓 | 界面统一叫「电脑」。 |
| 默认主题 | 跟随系统；设置里可切深色/浅色。 |
| 语言 | 跟随系统（zh-CN / en-US），中文兜底。 |
| 通知权限 | **每次启动检查** `POST_NOTIFICATIONS`；未授权时进入阻断页，授权后才能进 Tab。 |
| 首次启动 | 未配对 → 直接进入扫码页；配对成功后回「对话」Tab。 |
| 设计令牌 | `ZemoteColors` / `ZemoteType` / `ZemoteSpacing` / `ZemoteRadius`（已由 design/tokens 生成）。 |
| 圆角 | 卡片 12dp（rounded-xl）、输入坞 16dp（rounded-2xl）、徽标 full。 |
| 栅格 | 4dp 基准；页边距 12dp；卡内 12dp。 |
| 连接常驻 | 引擎会话挂在进程级容器（`AppContainer`），切 Tab / 进出页面都不重建；后台由前台服务保活。 |
| 本地缓存 | 打开过的对话按 `(workspaceKey, taskId)` 缓存最近 400 行到 `filesDir/chat-cache`；进页先显示缓存，快照到达后覆盖；删除任务时一并清除。 |

## 1. 对话 Tab（工作区/任务首页）

### 1.1 页头（单行，沉浸式）

```
[电脑名]                                [状态点] [状态文案]
```

- 左：电脑名（`label` 或配对时给的 `name`），单行截断。
- 右：连接状态点 + 文案（六态：idle / connecting / starting / running / active / error）。
- **不放刷新按钮、不放主题按钮**：刷新只靠下拉；主题在「设置 → 外观」。
- 高度：54dp（原 64dp 的 5/6）。
- 状态栏：页头背景延伸到状态栏下方（`statusBarsPadding()` 只压文字位置），
  状态栏图标与页头文字**不同行**。
- 页头下方：**仅异常时**出现可关闭横幅（连接降级 / 重连失败 / 服务端错误），
  内容 = 错误摘要 + 「重试」；恢复后自动消失。

### 1.2 列表

- 下拉刷新（唯一的刷新入口）。
- 数据：`workspace-list` 快照。**过滤 `workspacePurpose === 'conversation'` 的伪工作区**。
- 排序：工作区按内含任务的最晚 `updatedAt` 倒序；任务按 `updatedAt` 倒序。
- 置顶任务：从所属工作区**抽出**，在列表最上方独立成区（标题「已置顶」），
  原工作区不再重复显示；取消置顶回原工作区。
- 工作区横条（默认折叠）：
  ```
  [▸/▾] [图标] 工作区名 [远程]        [更新时间]
        /path/to/workspace          [+]
  ```
  - 图标：`workspacePurpose=conversation`→对话图标；`kind=remote`→远程图标；否则本地图标。
  - 标签：仅 `kind=remote` 显示「远程」；本地不显示标签。
  - 路径：等宽字体，单行截断；错误时下方红字显示 `lastConnectionError`。
  - 右侧：只显示最近更新时间；末尾「+」在该工作区新建对话。
  - 不显示任务数、未读数。
  - 折叠状态**不跨启动记忆**，每次启动全部折叠。
  - 有未读的工作区**自动展开且只显示未读任务**；再点一次横条（或展开箭头）
    切换为显示全部任务。
- 任务行：
  ```
  [状态槽] 标题                          时间
           [预览（仅未读/运行时，单行）]
                                  [状态pill]
  ```
  - 状态槽：运行中转圈 / 未读蓝点 / 置顶图钉，三者优先级：运行中 > 未读 > 置顶。
  - 标题：空则「未命名」。
  - 预览：`lastAssistantPreview`（来自 sessions-index），**仅未读或运行时显示**，单行截断。
  - 状态 pill：运行中（转圈）/ 已完成（勾）/ 错误（叉）+ 文字。
  - 未读：`unreadAt != null` 显示蓝点；进入对话页停留约 2 秒后调 `setTaskUnread(false)` 清除。
- 左滑任务行：露出三个按钮 **置顶 / 归档 / 删除**（删除二次确认）。
  三个动作都走 `task_call`（`setTaskPinned` / `archiveTask` / `deleteTask`）。
- 空状态：
  - 未配对：居中图标 + 「还没有连接电脑」+ 主按钮「扫码配对」+ 次按钮「粘贴配对链接」。
  - 已配对但无工作区：图标 + 「这台电脑还没有工作区」+ 刷新按钮。
  - 加载：骨架屏（3 条工作区横条占位）。
  - 错误：错误文案 + 重试。

## 2. 对话页

### 2.1 顶部

```
[‹] 任务标题
------------------------------------------
工作区名        [⋮]
/path/to/workspace
```

- 顶栏 44dp：返回 + 标题（单行截断）。**菜单下放到页内头部**。
- 页内头部：工作区名 + 等宽路径；右侧 ⋮ 菜单：置顶/取消置顶、重命名、归档、删除。
- 页面纵向三段：顶栏 / 头部 / `weight(1f)` 时间线 + 输入区。

### 2.2 时间线

- `LazyColumn`，按 `rowId` 作 key；只渲染窗口内行。
- 自动跟随：用户接近底部时新内容自动吸底；离开底部后显示「回到底部」浮动按钮。
- 上滑到顶自动 `rowsRange` 加载更早（最多 200 行/次，`beforeRowId` 游标）。
- 行类型与渲染（共 9 种）：

| kind | 渲染 |
|---|---|
| `turnHeader` | **只做工作段标题**：`工作中 1分23秒` / `已工作 1分23秒` / `已停止`，点击折叠/展开该段的工具与思考历史；流式段自动展开。不做文件变更摘要。 |
| `userInput` | 右对齐气泡，`rounded-xl + 右上角 rounded-xs`；正文 Markdown 内联；附件见 §2.4。 |
| `assistantText` | 左对齐正文，完整 Markdown（§2.3）。 |
| `reasoning` | 默认折叠「思考 · 3s」；流式时自动展开，完成后自动折起；用户手动展开后不再自动折。 |
| `toolCall` | 默认折叠一行：状态图标 + 工具名 + 参数摘要 + 耗时；流式时展开；**下一轮/下一个调用出现后自动折回**。点开展开输入/输出，超长内部滚动。 |
| `artifact` | 产物 pill：类型图标 + 文件名 + 大小；版本 ≥2 显示版本徽标；点击下载/预览。 |
| `subagent` | 卡片：类型 + 状态 + 摘要 + 耗时；**点击进入下一屏完整子代理页**（显示摘要全文、状态、子会话入口）。 |
| `hookInvocation` | 折叠一行：钩子事件名 + 执行数 + 状态 + 耗时。 |
| `timelineMarker` | 居中细标签：模型切换 / 压缩 / 分叉 / 目标 / 重试 / 检查点恢复。 |

- 消息长按菜单：**复制 / 重试 / 编辑 / 分叉**；后三者只在 `row.actions.canRetry/canEdit/canFork` 时出现。
- 图片点击 → 应用内全屏预览（双指缩放、双击放大、左右切换、下滑关闭）。

### 2.3 Markdown（原生实现，离线资源前置打包）

- 段落、标题、粗斜体、删除线、行内代码、有序/无序/任务列表、引用、分隔线、链接。
- 代码块：顶部一行 **语言标签 + 复制按钮**；保留缩进、横向滚动、语法着色
  （Kotlin/Java/Rust/JS/TS/Python/JSON/Shell/XML/YAML）；超过 30 行折叠。
- 表格：横向滚动，表头加粗，边框用 `border` 色。
- diff 代码块：`+` 行用 `diffAdded`，`-` 行用 `diffRemoved`。
- 图片：缩略图 + 点击全屏；加载失败显示占位。
- 公式：行内/块级用**离线打包的 KaTeX** 在本地 WebView 中渲染。
- mermaid：用**离线打包的 mermaid** 在本地 WebView 中渲染；失败时显示源码。
- 所有资源随 APK 打包，运行时不联网。

### 2.4 附件（用户气泡）

- 图片：48dp 缩略图，可多张网格。
- 其他文件：图标 + 文件名 + 大小的 pill。
- 上传中：进度环；失败：重试按钮。
- 输入区附件：回形针 → 系统文件选择器 → 上传（384 KiB/片，显示进度，可取消）。

### 2.5 输入区（composer）

```
┌───────────────────────────────────────┐
│ [队列卡片…]                            │
│ [待审批/待输入卡片…]                   │
│ ┌───────────────────────────────────┐ │
│ │ 多行文本输入（自动增高，最多 6 行）│ │
│ │ [📎] [模型/模式/思考]      [发送/停止]│ │
│ └───────────────────────────────────┘ │
└───────────────────────────────────────┘
```

- 文本：自动增高；运行中发送按钮变**停止**。
- 附件：回形针按钮。
- 模型选择：底部弹层，**与网页版完全对齐**：
  - Model：当前 provider/model（`configOptions` 缺失时只有当前值一项，只读）。
  - Mode：build / edit / plan / yolo（`switchCollaborationMode`）。
  - Effort：`thoughtLevels` 里的当前值与可选项（`switchModelConfig`）。
- 排队消息：完整队列卡片列表（序号、文本、删除、立即发送），数据来自 `queueItems`。
- 待审批/待输入：输入区上方固定卡片，显示权限名/命令预览与「允许 / 拒绝 / 总是允许」，
  同时发系统通知；不阻塞时间线。
- 新建对话：先进入空页（工作区名 + 路径 + 欢迎语 + 输入框），
  **发送第一条消息时才 `createSession`**；失败留在空页并提示。

## 3. 设置 Tab

顺序：**连接 / 外观 / 通知 / 关于与更新**。

### 3.1 连接
- 当前电脑卡片：名称、状态、最后连接时间。
- 「重新连接」。
- 「断开连接」（只断开，保留配对信息；不提供删除配对）。

### 3.2 外观
- 主题：跟随系统 / 深色 / 浅色。
- 界面字号倍率。
- 代码字号。

### 3.3 通知
- 通知总开关。
- 声音/震动开关。
- 事件勾选：任务完成 / 任务出错 / 等待授权或输入。
- 流体云状态（可用 / 系统已关闭 / 需 Android 16）+ 后台常驻开关。

### 3.4 关于与更新
- 当前版本 + 渠道 + 「检查更新」。
- 更新说明（有更新时）。
- 下载进度 / 暂停继续 / 安装。
- 启动后**静默检查**一次；有更新时在「设置」Tab 显示红点。

## 4. 配对页

- 全屏相机预览 + 中央扫描框 + 顶部关闭/手电筒 + 底部「从相册选择」「粘贴链接」。
- 扫码：CameraX + **ML Kit bundled 条码识别**（不依赖 Google Play 服务）。
- 链接格式：`https://<host>/remote/v4?sid=…&hash=…&t=…&mid=…&name=…`。
- 相机权限：每次进入都请求；永久拒绝时显示「去设置开启」+「改用粘贴链接」。
- 识别成功：校验 → 建立连接 → 直接回「对话」Tab；失败留在扫码页显示原因。

## 5. 通知与流体云

### 5.1 渠道

| 渠道 | 重要性 | 用途 |
|---|---|---|
| `keepalive` | MIN | 前台服务静默常驻 |
| `running_tasks` | LOW | 每个运行中任务一条常驻卡（可被提升为流体云） |
| `task_completed` | DEFAULT | 完成/出错通知（有声） |
| `task_attention` | DEFAULT | 等待授权/输入（有声） |

### 5.2 事件
- 任务完成、任务出错、等待授权/输入时发通知。
- 标题 = 任务标题；正文 = `lastAssistantPreview`；点击直达对话。
- 不发「新回复」类通知。

### 5.3 流体云（Android 16 Live Updates）
- 路径：`POST_PROMOTED_NOTIFICATIONS` + extras `android.requestPromotedOngoing` /
  `android.shortCriticalText`；不接 OPPO 泛在服务、不需要授权码。
- 覆盖：运行中任务、等待授权/输入、任务完成卡、下载进度卡。
- 按钮：
  - 运行中：无动作按钮，点卡片本体进对话。
  - 等待授权：直接显示「允许 / 拒绝」。
  - 已完成：显示「知道了」。
  - 下载：显示「暂停 / 取消」。
- 完成卡原地改状态，保留到用户点「知道了」；最多 3 张完成卡占提升位，超出降级为普通可滑除通知。
- 不支持（Android < 16 或系统关闭提升）→ 自动降级为普通通知。

## 6. 协议缺口与实现约定

| 项 | 约定 |
|---|---|
| `task_call` | 新增 FFI op：`setTaskPinned` / `setTaskUnread` / `renameTask` / `archiveTask` / `unarchiveTask` / `deleteTask`，走 `zcode-task` 通道。 |
| `lastAssistantPreview` | 来自 `sessions-index/<workspaceKey>` 订阅；Rust 已解析，界面按 `taskId` 合并。 |
| `prepareWorkspace` | 仍不发 RPC；模型选择器用当前 `config` 合成选项（与网页一致）。 |
| `queryConversationCommandsV4` | 不实现；斜杠命令不做自动补全。 |
| `attachmentAbortV4` | 不实现；上传失败由服务端 5 分钟 TTL 回收。 |
| `pluginUi.*` / `workflowRun.*` | 不渲染。 |
| 计划 / 目标 / 用量 | 不在头部显示；不新增独立面板。 |
