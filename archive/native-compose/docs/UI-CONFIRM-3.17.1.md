## 1. 已确认、继续执行（不需要再选）

### 1.1 对话页

- 顶栏 `h-11`（44px）：返回 + 标题 + 右侧动作；`bg-header` + 下边框。
- 页内头：工作区名 + 等宽路径 + ⋮ 菜单（置顶/重命名/归档/删除）。
- 时间线 9 种行，按 `rowId` 作 key：
  - `turnHeader`：只做工作段标题（工作中 / 已工作 / 已停止），点击折叠该段；
  - `userInput`：右对齐气泡，`rounded-xl` + 右上角小圆角，正文 Markdown；
  - `assistantText`：左对齐全 Markdown；
  - `reasoning`：默认折叠「思考 · Ns」，流式自动展开；
  - `toolCall`：默认一行（状态图标 + 工具名 + 参数摘要 + 耗时），可展开输入/输出；
  - `artifact`：类型图标 + 文件名 + 大小，版本 ≥2 显示版本徽标；
  - `subagent`：卡片（类型/状态/摘要/耗时），点击进子代理页；
  - `hookInvocation`：一行（事件名 + 执行数 + 状态 + 耗时）；
  - `timelineMarker`：居中细标签（模型切换/压缩/分叉/重试等）。
- 代码块：语言标签 + 复制；保留缩进、横向滚动、语法着色；diff 用增删色；超 30 行折叠。
- **不显示消息时间戳**；接近底部才自动吸底；上滑到顶加载更早（`beforeRowId`）。
- composer：`rounded-2xl` dock；多行自动增高（最多 6 行）；附件 / 模型 / 模式 / 发送（运行中变停止）；
  队列卡、待审批 / 待输入卡固定在输入框上方。
- 附件：用户气泡里的图片 **80×80dp、圆角 12、间距 8**（只读态）；48dp 仅用于编辑态；其他文件 pill 高 32dp；上传进度 / 失败重试。

### 1.2 全局

- 主题：**跟随系统**；系统深色 → `zai-dark`，系统浅色 → `zai-light`。
  手动切换只在「设置 → 外观」，**首页不放主题菜单**。
- 字体：系统 sans（不打包 Inter）；等宽用 monospace；正文 14sp；Markdown 正文行高 1.75，UI 行 1.5，代码 20px。
- MD3 只保留行为（ripple / 无障碍 / IME），首页与对话页的视觉件全部自绘。
- 底部导航如需保留，也自绘成网页风，不用 M3 NavigationBar 默认件。

## 2. 首页：3.17.1 结构与待拍板项

### 2.1 3.17.1 实际结构（项目树）

- 项目/任务树，两种视图：分组（按项目） / 列表（按时间）。
- 置顶项目/任务排前；支持展开/折叠全部、排序、刷新、新建。
- 项目行：16px 图标 + 项目名 + 设备标签 + 未读点（sky-500）+ 离线标签 + 操作菜单。
- 任务行：状态槽（运行中转圈 / 未读点 / 图钉）+ 标题 + 时间/预览 + 状态徽标；
  行高 ≥48px（`min-h-12`），圆角 8（`rounded-lg`）。
- 选中态 `bg-selected`；悬停 `bg-surface-hover`（移动端用按压态替代）。
