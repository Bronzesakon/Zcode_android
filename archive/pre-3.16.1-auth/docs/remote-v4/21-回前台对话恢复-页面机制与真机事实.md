## 0. 一句话

页面**自己有一套完整的连接恢复通路**，对"回前台"**只认四个信号**（`visible|pageshow|online|resume`）
**并且要求"传输已降级"**才会真正重开工作区与重订阅。**这条总结论在 3.15.3 上仍然成立**，
但健康路径**不再"只重拨 socket 就 return"**：现在会多跑一次 `L()`（bootstrap 版本闸门）。
"回到哪个会话"仍由三条互不相干的状态拼出来：`history.state.zcodeMobilePage`（落 chat 还是 home）、
**localStorage 槽位**（chat 里打开哪个会话，**仅 reload 路径**）、relay `mobileViewState`（跨进程）；
**3.15.3 新增了第四条**：`popstate` 事件直接驱动页状态。

### 2.4 三条（四条）通路如何合起来决定"你看到什么"

```
冷启动（navigate）      → ① history.state 命中则 chat，否则 home；② 槽位【不读】
点刷新 / 宿主 reload    → ① 命中则 chat；② 槽位【读】，要求当前无会话 ⇒ 打开上次会话
进程被杀后重新打开       → ① 归零（不跨进程）⇒ 落 home；② 槽位【读】但页面没进 chat 也无意义
浏览器后退到 home       → ④ popstate ⇒ 页状态改 home + refreshKey++（首页重拉）
```

> **对原生宿主的直接结论**：宿主"写槽位 + 钉 `history.state` + `reload()`"这一套
> **正好命中 ① 与 ②**（因为宿主确实执行了 reload，`jQ()` 为真）。
> 这不是"机制被短路"，而是"**只在 reload 路径上生效**"。

## 3. 真机形态学 —— **未复核（旧基线）**

> ⚠️ **本节整节沿用 2026-09-20 观测，本次未复核**（无新真机样本）。
> 结论仅作历史记录，**不得当作 3.15.3 的实测结论引用**。

旧基线把"回前台后对话有没有回来"分三形态，用档 0 判据（退后台采快照 + 回前台 3s 首判 / 12s 复判）观测：

| 形态 | 现象 | 判据（旧壳侧） | 与页面机制的关系 |
| --- | --- | --- | --- |
| **S1** | 回来就在对话里 | 3s 判 `chat=true` | `recoverConnection()` 重拨成功 + 页面状态未丢 |
| **S2** | 3s 没回来、12s 回来了 | 3s `chat=false`，12s `chat=true` | 重拨要时间 |
| **S3** | 12s 仍未回到对话 | 3s 与 12s 都 `chat=false` | 页面落 home ⇒ 旧壳执行档 3：钉 `history.state` + `reload()` |

- 旧基线记录：进程被杀后重载**仍落 home**、内容**永远不来**的现场持续 **5 分 46 秒**（S3 极端形态）。
- 旧壳档 3 有跨进程限流闸门（连续 2 次 + 5 分钟最小间隔，到顶停手，`ConversationRecoveryPolicy`）。

## 4. 页面 / 宿主两侧的职责边界

| 问题 | 页面侧做了什么（3.15.3 已复核） | 原生宿主该做什么 |
| --- | --- | --- |
| 回前台连接断了 | `suspend()` → `recoverConnection()`（转 `reconnecting` + `pair_status_query`，最多等 3s 再重拨） | 交付**可见性恢复**；**不要**替页面重连 |
| 回前台内容没回来 | 白名单信号 + 健康 ⇒ 只跑 `L()`（版本闸门）后 return；**只有降级才重开** | 观测 + 主动干预（钉 state + reload），并限流 |
| 版本不一致 | `s6n.check()`：`desktopAppVersion` ≠ URL `app_version` ⇒ `isPageReady()? onMismatch(弹窗) : navigate(改 URL 重载)` | **必须回带 `desktopAppVersion`**，否则走"字段缺失直接返回"分支 |
| 连接被抢 | `KICKED` 进终态，不重连 | 宿主侧自愈（回前台重载一次，cap 2） |
| 冷启动落哪 | `Mbn()` 判 `history.state` | 无需干预 |
| 重载后打开哪个会话 | `mun` + `pun`（要求 `navigation.type==='reload'`） | 若要指定会话：**写槽位 + reload** |
