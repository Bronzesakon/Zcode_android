### 2.3 语义要点（实测于代码）

- `setEnabled` 只写 `~/.zcode/cli/config.json` 的 `skills[path]={enable}`，
  **不校验 `scope`**（传了也被忽略），找不到 `skillId` 抛 `Skill not found: <id>`。
- `copyToCommon`：把技能复制到用户通用目录；目标已存在同名目录抛
  `通用目录已存在同名技能: <name>`；成功返回 `{newPath}`。
- `removeFromCommon`：只允许删除位于用户通用目录或工作区通用目录下的技能，
  否则抛 `该技能不在通用目录中`。
- `deleteSkill`：`scope==="plugin"` 抛 `插件提供的技能不可单独删除，请卸载对应插件`；
  目标必须在工作区/用户/agents 技能根内，否则抛 `该技能不可删除: <path>`。
- `buildPromptContext`：从 prompt 中提取 `$skill-name` 提及，命中已启用技能时把
  `<available_skills>` 块拼到 prompt 末尾，并写审计日志 `skills-audit.log`。

## 14. 一句话给实现方

- **技能/子代理/命令/Hook/记忆**：直接用同名通道方法，参数就是上表；
  返回对象**没有外层包装**（不是 `{result:...}`），直接是方法体 return 的对象。
- **插件**：不要用 `plugins` 通道（本构建是退役桩）；用 `plugin-management` 或
  `zcode-agent` 的同名方法。
- **MCP**：读配置用 `mcp-sync.loadMcpFromUserDirectory`，读实时状态用
  `listWorkspaceMcpServerStatuses`，写用 `saveMcpToUserDirectory`（三个 action）。
- **用量**：`getAppUsageSnapshot` 与 `getSnapshot`/`getCodingPlanUsageSnapshot` 是两套数据源
  （`agent-db` vs BigModel monitor），字段不同，别混用。
- **定时任务**：只在 `zcode-agent`，且 `listAllAutomations` 无参数、`create/update`
  不透传 `intervalUnit`/`interval`。
